# WEB PANEL ONLINE 3.0 — единый синий установщик v26 (тест)

**Ветка:** `test/wpo-3-unified-blue-v26`.

Ветка собрана от `test/legacy-v26-pre-consolidation-20261112` (версия с работающим VLESS XHTTP). Основной `main` не изменён.

## Состав

- `install.sh`: синий интерактивный мастер с рамкой, четырьмя последовательными строками `ШАГ 1/4` ... `ШАГ 4/4` (без отдельных плиток с цифрами и без большой кнопки). Широкая полоса `█`/`░` показывает фактически достигнутый этап; время `Прошло: чч:мм:сс` отсчитывается от начала подготовки и загрузки пакета. Процент этапный, не прогноз оставшегося времени. Неинтерактивный режим сохранён.
- `install-webproxy-core.sh`: сохранена прежняя работающая сборка прокси, добавлены безопасная передача данных мастера и этапы прогресса.
- `install-panel.sh`: итоговая карточка выводится полностью **на русском**: «Ссылка на панель: https://…», «Логин : …», «Пароль : …» — каждое поле в своей строке с пустым интервалом; внизу «Сохраните данные,что бы не потерять!». Она попадает в защищённый временный файл и показывается только после успешной установки; токен Node API в карточке отсутствует.
- `install-final.sh`: единый этап Nodes Lab v26 и проверка Xray, без запуска компонента с клиентами, которых ещё нет.
- `node-install.sh`: все 26 скриптов Nodes Lab в одном файле; при прохождении обновляется прогресс `Ноды: этап N/26`, промежуточные перезапуски отключаются для пакетного прохода, после него выполняются один restart и локальная проверка HTTP-health.
- `wpp_ui.py`: одиночный VLESS всегда отдаёт Happ-профиль с названием клиента даже при выключенной маршрутизации; название ноды отдельно.

## Перед тестированием на VPS

Использовать **отдельный чистый VPS** или восстановленный снимок. Не ставить поверх рабочего сервера без резервной копии.

Не менять домен/сертификат рабочей панели и не запускать одновременно другой инсталлятор. Для ручного теста нужен настоящий терминал SSH, чтобы открылось интерактивное меню.

## План проверки

1. В SSH открылся синий мастер: заголовок в рамке, `ENTER — установить`, `q — выход`, нет большой кнопки.
2. После ENTER каждый шаг появляется **только после завершения предыдущего**: домен → ACME email → логин → **один скрытый пароль после двоеточия** → немедленный старт установки. «Повторите пароль» нет. Пароль короче трёх символов вводится заново.
3. Стартовый экран без отдельной плитки с номером; у каждого вопроса один заголовок `ШАГ N/4` и поле ввода. Широкая полоса `█` меняется по фактически пройденным этапам, без искусственного 1% каждые 0,2 секунды. Статус этапа и реальное время `Прошло: чч:мм:сс` находятся на отдельных строках. При установке нод виден номер этапа из 26.
4. Установка дошла до 100% без ошибок; в финальной карточке показаны **Ссылка на панель: адрес**, **Логин : значение**, **Пароль : значение** с пустыми строками между ними и напоминанием **«Сохраните данные,что бы не потерять!»**. Без токена ноды; скриншот с паролем нельзя публиковать.
5. В панели доступны «Ноды», флаги, карточки, статусы и шаблоны; нет падения `tproxy-panel.service` как раньше на этапе v6.
6. Создать одиночного клиента VLESS XHTTP без маршрутизации. Импортировать в Happ, проверить пинг, интернет и заголовок (имя клиента).
7. Убедиться, что название ноды осталось `флаг + страна`, а не имя клиента.
8. Включить маршрутизацию и заново импортировать профиль: название остаётся, подключение работает.
9. Проверить раздел «Службы и версия» и локальную/внешнюю доступность панели.
10. Перезагрузить VPS, проверить автозапуск служб, соединение Happ и состояние раздела нод.

## Примечания

- Проверки GitHub Actions охватывают синтаксис, исходники 26 скриптов и важные структурные инварианты; они **не заменяют испытание на живом VPS**.
- В Nodes Lab v26 удалённые Node Agent пока дают регистрацию, HTTPS, состояние и шаблоны; полноценный VPN на удалённой ноде этим выпуском не добавляется.
- Старые скрипты `wpo-nodes-lab-*.sh` пока сохранены для аудита и сравнения. Удалить только после подтверждения теста.
- Не менять `main` до подтверждения пользователем.
