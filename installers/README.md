# Внутренние установщики WPO

Здесь лежат части установочного пакета, которые вызывают публичные команды из корня репозитория. **Вручную запускать их не требуется.**

- Установка панели: [`../install.sh`](../install.sh)
- Установка ноды: команда из интерфейса WPO, либо [`../node-install.sh`](../node-install.sh) в составе полного пакета
- Обновление: [`../update.sh`](../update.sh)

Временные ссылки со старыми именами создаёт [`../scripts/prepare-source-layout.sh`](../scripts/prepare-source-layout.sh), поэтому пути модулей и логика VPS сохраняются.
