<h1 align="center">WEB PANEL ONLINE 3.0.0</h1>

<p align="center">Панель управления VPN и Proxy подключениями на собственном VPS. Поддержка VLESS XHTTP, Hysteria2, AmneziaWG, NaiveProxy, Mieru, MTProto и экспериментальная интеграция OpenFlux.</p>

---

## Возможности

- Подписки и отдельные подключения с QR-кодами и готовыми конфигурациями.
- VLESS XHTTP и Hysteria2, включая прямые и CDN-подключения VLESS.
- Отдельные профили AmneziaWG 2.0 и 3.1 с QR-кодом и файлом `.conf`.
- NaiveProxy и Mieru с отдельным портом для каждого серверного подключения, ссылкой и QR-кодом.
- Профили MTProto и Telegram Web Proxy; экспериментальная интеграция OpenFlux.
- Управление пользователями, ограничениями устройств, трафиком и состоянием служб.
- Раздел «Ноды»: основная нода определяется автоматически по стране VPS и отмечается звёздочкой; дополнительные VPS подключаются через одноразовый установщик Node Agent 0.2.
- Автоматическое определение страны и флага, живые статусы, карточки установки и управление названием нод.
- Шаблоны HTTPS-сайтов для дополнительных нод: автоматический выбор при добавлении и применение любого выбранного шаблона сразу после сохранения.
- HTML-страницы, CSS, JavaScript, SEO и аналитика.
- Проверка обновлений и безопасное обновление с временным автоматическим откатом.
- Экспорт и импорт полной резервной копии настроек через браузер.

## Требования

- Чистый VPS с Ubuntu 22.04+, Ubuntu 24.04+ или Debian 12+.
- Архитектура `x86_64` и доступ пользователя `root`.
- Домен или поддомен с A-записью на публичный IPv4 сервера.
- Свободный и открытый `443/tcp`. Порт `80/tcp` панель не занимает.

Перед установкой убедитесь, что домен уже указывает на сервер. Дополнительные порты выбранных подключений нужно открыть во внешнем firewall VPS-провайдера.

## Быстрый старт

Подключитесь к серверу по SSH и перейдите в режим `root`:

```bash
sudo -i
```

### Установка

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/main/install.sh" -o /tmp/wpo-install.sh && bash /tmp/wpo-install.sh; code=$?; rm -f /tmp/wpo-install.sh; exit $code'
```

Новый **русскоязычный мастер установки** открывается прямо в SSH-терминале: «Установить» → домен → email → логин → скрытый ввод пароля с подтверждением. Вместо потока APT/Go-сообщений показываются подтверждённые этапы с процентами и анимированным индикатором. Подробный журнал остаётся на VPS в `/var/log/web-panel-online/install-*.log` (доступ только root).

После всех проверок и настройки нод **последним экраном** отображаются адрес панели, логин и пароль. При обновлении существующей панели учётные данные сохраняются. Для запуска классического текстового режима можно использовать `WPO_CLASSIC_INSTALL=1`.

Подготовка системных зависимостей и параллельная загрузка Caddy/Go выполняются в начале установки. Целевая скорость — около **5 минут на подготовленном VPS**; фактическое время зависит от загрузки CPU, репозиториев Ubuntu, DNS и выдачи TLS-сертификата. Ошибки лимита Let's Encrypt обрабатываются без долгого ожидания.

**Ноды:** основной установщик запускает один `node-install.sh` со всеми 26 проверенными этапами Node Lab (по результатам сверки их исходных текстов). Старые отдельные скрипты пока оставлены для обратной совместимости и отката до успешной проверки чистой установки.

### После установки

1. Сохраните адрес панели, логин и пароль в безопасном месте.
2. Откройте HTTPS-адрес панели и создайте пользователя или отдельное подключение.
3. Скачайте конфигурацию, скопируйте ссылку либо отсканируйте QR-код подходящим клиентом.
4. В разделе **Ноды** уже появится основная нода с флагом страны VPS и звёздочкой. Для дополнительного VPS откройте **Ноды → Добавить ноду**, получите одноразовую команду и выполните её на новом VPS.

### Дополнительные ноды

Для Node Agent 0.2 нужен отдельный VPS с доменом, A-записью на его IPv4 и открытыми портами `80/tcp` и `443/tcp` (включая firewall провайдера). В окне редактирования ноды можно менять имя и выбирать готовые шаблоны сайтов. После сохранения сайт публикуется непосредственно на ноду, а карточка показывает «Шаблон: …».

**Текущие возможности Node Agent 0.2:** управление HTTPS-страницей, шаблонами и состоянием ноды. VPN-протоколы и включение удалённой ноды в клиентские подписки через этот агент **пока не реализованы**.

### Обновление только пресетов сайтов (без переустановки VPS)

После обновления галереи **Настройки → Пресеты заглушек** кнопка «Предпросмотр» открывает изолированную страницу прямо из карточки. «Применить» публикует выбранный шаблон с проверкой результата; редактор полного HTML скрыт из основных настроек. Для «Автосалона» и кофейни используются локальные фотографии. Встроенные и собственные пресеты, их удаление, другие настройки панели и Nodes Lab сохраняются.

Для обновления **уже установленной панели**:

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/main/wpo-presets-fast-update.sh" -o /tmp/wpo-presets-update.sh && bash /tmp/wpo-presets-update.sh; code=$?; rm -f /tmp/wpo-presets-update.sh; exit $code'
```

Скрипт создаёт резервные копии изменяемых модулей и проверяет предпросмотр, фото и доступность панели. На новом VPS изменения входят в обычный установщик. Если «Автосалон» уже был опубликован до обновления, примените его повторно, чтобы обновилась таблица стилей с локальными фотографиями.

### Обновление

```bash
/usr/local/sbin/web-panel-proxy-update
```

Для обновления **только раздела «Настройки → Пресеты заглушек»**, без полной установки и пересборки VPN-компонентов:

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/main/wpo-presets-fast-update.sh" -o /tmp/wpo-presets-update.sh && bash /tmp/wpo-presets-update.sh; code=$?; rm -f /tmp/wpo-presets-update.sh; exit $code'
```

В галерее пресетов предпросмотр открывает сайт прямо в отдельном окне, не изменяя рабочую страницу. Кнопка «Применить» публикует выбранный шаблон и показывает результат или ошибку. Фотографии встроенных шаблонов «Автосалон» и «Кофейня» включаются непосредственно в CSS публикации; исходный HTML сохраняется без изменений. Большой HTML-редактор удалён из главного интерфейса настроек, но создание собственного пресета доступно по кнопке «Создать».

Обновление устанавливает последний стабильный релиз и сохраняет пользователей, ключи, настройки, адрес панели и HTML-страницы.

### Удаление

```bash
/usr/local/sbin/web-panel-proxy-uninstall
```

> **Внимание:** удаление выполняется без дополнительного подтверждения и стирает пользователей, ключи, конфигурации, службы и сайт панели.

## Сеть и порты

| Назначение | Порт |
|---|---:|
| HTTPS, панель, защищённые подключения и продление сертификата | `443/tcp` |
| Hysteria2 по умолчанию | `8443/udp` |
| MTProto | выбранный порт, обычно `2399–2430/tcp` |
| NaiveProxy | отдельный порт подключения, по умолчанию от `53000/tcp` |
| Mieru | отдельный порт подключения, по умолчанию от `54000/tcp` или UDP |

Для Shadowrocket используйте ссылку Mieru `mierus://` или её QR-код. В настройках клиента также доступен полный профиль `mieru://` для официального приложения mieru CLI. Это два варианта экспорта одного ключа; создавать нового пользователя не нужно.

Если для отдельного VLESS/Hysteria2 включена маршрутизация, основная кнопка копирования и QR передают в Happ ссылку на полный JSON одного сервера. В настройках пользователя доступны просмотр, копирование и скачивание JSON. Обычная `vless://`-ссылка сохранена отдельно. После изменения правил обновите JSON-профиль в Happ.

Для NaiveProxy и Mieru доступны отдельные ключи без подписки, учёта трафика и ограничений по трафику или числу устройств. После изменения настроек ключа обновите его в приложении.

Caddy использует `443/tcp`; сертификат выпускается и продлевается через TLS-ALPN без постоянного HTTP-слушателя. Порт `80/tcp` остаётся свободным. Если используется UFW, панель добавит свои правила, но firewall у VPS-провайдера необходимо настроить отдельно.

## Проверка состояния

JSON существующего VLESS/Hysteria2 открывается карандашом в строке подключения → «Конфигурация Xray». Это серверный inbound выбранного подключения, а не общий конфиг службы. При сохранении согласовываются маршруты Caddy, клиентские ссылки и UDP-порт Hysteria2; неверная конфигурация откатывается.

Открыть консольное меню:

```bash
WPP
```

Проверить службы и последние сообщения панели:

```bash
systemctl --failed --no-pager
journalctl -u tproxy-panel.service -n 100 --no-pager
```

Проверить занятые порты:

```bash
ss -lntup
```

## Полезно знать

- Адрес панели, Node API token и ссылки подключений являются секретными — не публикуйте их.
- Для отката обновления создаётся временный снимок, который автоматически удаляется после проверки.
- QR-код OpenFlux содержит данные доступа. Не публикуйте его и удаляйте профиль при потере устройства.
- Статус «Работает» у профиля OpenFlux означает, что его служба запущена; наличие интернет-трафика проверяется отдельно.
- OpenFlux — экспериментальная IPv4-интеграция. Совместимость UDP зависит от клиента и режима; IPv6-туннель не предоставляется.
- Скачиваемые резервные копии содержат пароли и ключи — храните их безопасно и не загружайте в публичный репозиторий.
