<h1 align="center">WEB PANEL ONLINE 3.0.0 (WPO)</h1>

<p align="center">WEB Proxy, MTProto, VLESS XHTTP, Hysteria2, AmneziaWG, NaiveProxy, Mieru, OpenFlux и управление подключениями на собственном VPS.</p>

---

## Возможности

- Подписки и отдельные подключения с QR-кодами, ссылками и готовыми клиентскими конфигурациями.
- VLESS XHTTP и Hysteria2, включая прямые подключения VLESS и работу через CDN.
- Отдельные профили AmneziaWG 2.0 и 3.1 с QR-кодом и файлом `.conf`.
- NaiveProxy и Mieru: отдельные ключи, ссылки и порты для каждого подключения.
- MTProto и Telegram WEB Proxy; экспериментальные сценарии OpenFlux с внешними сервисами, в том числе Яндекс Документами, Телемостом, Mail.ru и MAX.
- Пользователи, сроки действия, лимиты устройств и трафика, мониторинг служб, резервное копирование и восстановление.
- Управление доступом из браузера с уведомлениями о включении и отключении.
- Раздел **«Ноды»**: основная нода и дополнительные VPS в одной панели, отображение страны и флага, установка через одноразовую команду Node Agent.
- Подключения VLESS XHTTP и Hysteria2 на выбранных нодах, клиентские подписки Happ и автоматический выбор доступного сервера.
- Маршрутизация отдельных подключений, правила для доменов и сетей, импорт готовых списков для AmneziaWG.
- Готовые и собственные HTTPS-страницы: HTML, CSS, JavaScript, SEO, аналитика и шаблоны для дополнительных нод.
- Проверка обновлений и восстановление предыдущего состояния при ошибках обновления.
- Экспорт и импорт полной резервной копии через браузер.

## Требования

- Чистый VPS: **Ubuntu 22.04 / 24.04 LTS** или **Debian 12**, архитектура `x86_64`.
- Доступ `root` или пользователь с `sudo`.
- Домен или поддомен с **A-записью** на публичный IPv4 VPS.
- Открытый `443/tcp`. Порт `80/tcp` на основной панели не занимает постоянная служба WPO.
- Дополнительные порты прокси-протоколов должны быть разрешены также во внешнем firewall VPS-провайдера.

Перед установкой дождитесь обновления DNS. Для дополнительных нод проверьте доступность `80/tcp` и `443/tcp` — они могут использоваться при регистрации и получении HTTPS-сертификата.

## Быстрый старт

Подключитесь по SSH. Для входа в режим администратора:

```bash
sudo -i
```

### Установка с GitHub

```bash
sudo bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/main/install.sh" -o /tmp/wpo-install.sh && bash /tmp/wpo-install.sh; code=$?; rm -f /tmp/wpo-install.sh; exit $code'
```

Русскоязычный мастер попросит домен, email для TLS-сертификата, логин и пароль панели. После завершения установки на экране появятся HTTPS-адрес панели и учётные данные. Подробный журнал записывается в `/var/log/web-panel-online/` (доступ только root).

Существующую установленную панель не следует повторно устанавливать этой командой: используйте **обновление**, описанное ниже.

### Локальная установка из ZIP

Исходный ZIP можно скачать на компьютер или прямо на чистый VPS: **[Скачать WPO (main.zip)](https://github.com/TonyMaster14/web-panel-online/archive/refs/heads/main.zip)**.

Для установки из ZIP, уже скопированного на VPS как `/root/WPO-main.zip`:

```bash
sudo -i
apt-get -o DPkg::Lock::Timeout=600 install -y unzip
d=$(mktemp -d /root/wpo-install.XXXXXXXX)
unzip -q /root/WPO-main.zip -d "$d"
cd "$d/web-panel-online-main"
bash ./install.sh
```

Установщик автоматически подготавливает файлы из внутренних папок. ZIP содержит исходники и собранные компоненты, но для системных пакетов, проверки DNS и выпуска сертификата серверу всё ещё может требоваться интернет.

### После установки

1. Сохраните HTTPS-адрес панели, логин и пароль. Не передавайте никому Node API token и ссылки с ключами.
2. Откройте панель и создайте пользователя или отдельное подключение.
3. Добавьте подписку в Happ, скопируйте конфигурацию либо отсканируйте QR-код.
4. В разделе **«Ноды»** увидите основной сервер. Для другого VPS нажмите **«Добавить ноду»**, скопируйте созданную команду и выполните её **на дополнительном VPS**.

Для нод используются отдельные домены. Управление и создание пользователей выполняется через **основную панель WPO**. Включайте в подписку только те серверы и протоколы, которые действительно настроены и доступны.

## Обновление

### Обычное обновление

На уже установленной основной панели:

```bash
/usr/local/sbin/web-panel-proxy-update
```

Это обновление использует опубликованный стабильный тег GitHub. Оно сохраняет адрес панели, пользователей, подписки и настройки. **Тег и ветка `main` могут содержать разные версии** — для обновления именно из текущего `main` используйте ZIP ниже.

### Локальное обновление из ZIP

Для VPS, на котором **WPO уже установлена**, сначала получите актуальный ZIP с GitHub либо загрузите файл `WPO-main.zip` вручную в `/root`.

```bash
sudo -i
apt-get -o DPkg::Lock::Timeout=600 install -y unzip curl
curl -4fL --retry 3 "https://github.com/TonyMaster14/web-panel-online/archive/refs/heads/main.zip" -o /root/WPO-main.zip
d=$(mktemp -d /root/wpo-update.XXXXXXXX)
unzip -q /root/WPO-main.zip -d "$d"
cd "$d/web-panel-online-main"
bash ./update.sh --local
```

Если ZIP уже загружен в `/root/WPO-main.zip`, просто **пропустите строку `curl`**. Перед запуском рекомендуется выгрузить резервную копию настроек через панель.

Обновление `--local` использует файлы **именно распакованного ZIP**, а не подменяет их содержимым другого тега. Оно создаёт временную копию для отката и проверяет результат; пользовательские данные не предназначены для удаления. Не запускайте на действующей панели `install.sh` вместо `update.sh`.

### Удаление

```bash
/usr/local/sbin/web-panel-proxy-uninstall
```

> **Внимание:** удаление не запрашивает дополнительного подтверждения и стирает данные панели, пользователей, ключи, конфигурации и связанные службы.

## Сеть и порты

| Назначение | Порт |
|---|---|
| HTTPS, панель, защищённые подключения и продление TLS-сертификата | `443/tcp` |
| Hysteria2 по умолчанию | `8443/udp` |
| MTProto | назначенный порт, обычно `2399–2430/tcp` |
| NaiveProxy | индивидуальный порт, обычно от `53000/tcp` |
| Mieru | индивидуальный порт, обычно от `54000/tcp` или UDP |

MTProto использует служебные данные Telegram; при сетевой недоступности источника установщик может воспользоваться проверенными резервными файлами. Успешная загрузка этих файлов сама по себе не доказывает доступность Telegram-серверов.

Для Shadowrocket у Mieru предусмотрена ссылка `mierus://`; для официального mieru CLI — профиль `mieru://`. Это два способа экспорта одного подключения.

## Маршрутизация и Happ

Для отдельного VLESS/Hysteria2 с включённой маршрутизацией доступен полный клиентский JSON, содержащий необходимые параметры DNS и маршрутов. В панели можно просмотреть, скопировать или скачать конфигурацию. Обычная ссылка `vless://` остаётся отдельным вариантом подключения. После изменения правил обновите JSON-профиль в Happ.

Автоматический выбор работает между настроенными серверами подписки: он не заменяет регистрацию нод и не создаёт недостающие серверные профили самостоятельно.

У NaiveProxy и Mieru используются отдельные ключи; ограничения подписки, лимиты устройств и статистика трафика могут не применяться к ним так же, как к VLESS/Hysteria2.

## Проверка состояния

Откройте консольное меню:

```bash
WPP
```

Проверьте службы, сообщения и занятые порты:

```bash
systemctl --failed --no-pager
journalctl -u tproxy-panel.service -n 100 --no-pager
ss -lntup
```

JSON серверного VLESS/Hysteria2 настраивается через карандаш рядом с подключением → **«Конфигурация Xray»**. Не заменяйте UUID, пароль и управляемые параметры вручную: эти поля настраиваются через разделы пользователей и маршрутизации.

## Безопасность и примечания

- Не публикуйте закрытый путь панели, пароли, Node API token, ссылки подписок и QR-коды с ключами.
- Экспортированные резервные копии содержат чувствительные данные. Храните их в безопасном месте.
- Для OpenFlux может требоваться отдельная публичная ссылка или конференция на каждого клиента. Это экспериментальная интеграция; статус службы не гарантирует реальный трафик, а поддержка UDP и IPv6 зависит от сценария.
- Использование CDN, сетевых маршрутов и клиентских JSON-профилей зависит от настроек сервера и поддерживаемых возможностей приложения.
