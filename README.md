<h1 align="center">WEB PANEL ONLINE (WPO) · 3.0</h1>

<p align="center">Управление VPN, Proxy, пользователями, подписками и дополнительными нодами на собственном VPS.</p>

## Быстрый старт

**Сервер:** Ubuntu 22.04 / 24.04 или Debian 12, x86_64, root, домен с A-записью на VPS и открытый 443/tcp.

```bash
sudo bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/main/install.sh" -o /tmp/wpo-install.sh && bash /tmp/wpo-install.sh; code=$?; rm -f /tmp/wpo-install.sh; exit $code'
```

Мастер установки попросит домен, email, логин и пароль. Установка дополнительной ноды запускается через **Панель → Ноды → Добавить ноду**.

**Обновить установленную панель:** `/usr/local/sbin/web-panel-proxy-update`  
**Консольное меню:** `WPP`  
**Удалить панель и её данные:** `/usr/local/sbin/web-panel-proxy-uninstall` (без подтверждения).
