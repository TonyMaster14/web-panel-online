# WPO — компоненты дополнительных нод

Эти файлы входят в пакет WPO и используются основным установщиком и разделом **Ноды → Добавить ноду**.

Не запускайте компоненты по одному на VPS. Используйте команду установки, полученную из основной панели WPO. При подготовке пакета скрипт [`../scripts/prepare-source-layout.sh`](../scripts/prepare-source-layout.sh) восстанавливает совместимые пути без изменения файлов сервера.
