# Служебные и исторические скрипты WPO

Эта папка хранит разовые исправления и диагностику из истории разработки. **Для установки WPO используйте корневой [install.sh](../install.sh), для ноды — команду, сгенерированную панелью.**

- [routing/](routing/) — история изменений маршрутизации и интерфейса.
- [happ/](happ/) — диагностика и исправления Happ, подписок, нескольких нод.
- [nodes/](nodes/) — скрипты восстановления и доработок дополнительных нод.
- [users/](users/) — изменения создания и удаления пользователей, Federation.
- [other/](other/) — прочие временные исправления.

## Совместимость и откат

Рабочие установщики и модули в корне **не переносились**. Исторические файлы перенесены с сохранением их содержимого в Git. Если нужен старый одноразовый URL из чата, он остаётся доступен через исходный неизменяемый коммит `2c0d79383660a2de3e3681609f07f403678b0ce5`, например:

```
https://raw.githubusercontent.com/TonyMaster14/web-panel-online/2c0d79383660a2de3e3681609f07f403678b0ce5/wpo-routing-custom-inset-v8-test-install.sh
```

Не запускайте патчи последовательно поверх новой WPO: многие из них уже встроены в актуальный код. Ссылки старых патчей с указанием точного коммита сохранены для воспроизводимости, а не рекомендованы для новой установки.
