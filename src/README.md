# WPO — исходные Python-модули

Исходные модули панели и нод хранятся здесь, чтобы корень репозитория оставался коротким.

Установщики автоматически готовят временные совместимые ссылки в папке распакованного пакета с помощью [`scripts/prepare-source-layout.sh`](../scripts/prepare-source-layout.sh). **В установленной панели пути не меняются:** рабочие файлы по-прежнему находятся в `/opt/tproxy-panel/`.

Не загружайте модули по отдельности на VPS. Используйте основной [`install.sh`](../install.sh).
