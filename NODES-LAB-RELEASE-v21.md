# WEB PANEL ONLINE — Nodes Lab v21 (сохранённая версия)

**Ветка:** `nodes-lab`  
**Основная ветка `main`:** не изменялась.  
**Последний визуальный патч:** `wpo-nodes-lab-v22-install.sh`  
**Зафиксированный снимок исходников:** `5197777c65ad2350d8cf3f4fef4ac0a59e51d2c0`  
**Универсальный установщик:** [`wpo-nodes-lab-release-v22-install.sh`](./wpo-nodes-lab-release-v22-install.sh)

Это контрольная точка экспериментальной интеграции дополнительных VPS-нод с панелью WPO 3.0. Исходники обновлений v1–v21 и модули Node Agent, GeoIP и выбора шаблонов сохранены **в этой ветке**. Для восстановления набора изменений с нуля нужно сначала установить базовую WPO 3.0, затем применить общий установщик. Это не самостоятельный установщик всей панели.

## Что вошло в сохранённую версию

- Регистрация дополнительных нод из интерфейса через одноразовый установщик с ограниченным сроком действия, HTTPS/Caddy и Node Agent 0.2.
- Отображение основной и дополнительных нод, флаги стран, геолокация с резервными провайдерами, автоматические названия стран и сохранение пользовательских имён при переименовании.
- Проверка состояния удалённых агентов: обновление браузера каждую секунду, фактический запрос статуса примерно раз в 5 секунд, тайм-аут соединения 3 секунды. Статусы и статистика «В сети/Не в сети» обновляются без ручной перезагрузки.
- Компактные карточки одинаковой высоты, совпадающий уровень доменов и голубых глобусов, значок основной ноды, тонкие разделители, кнопки редактирования/удаления у дополнительных нод, оформление заголовка «Управление нодами». Патч v22 исправляет карточку установки: её статус, домен и ход установки целиком внутри карточки; новые ноды заполняют первую строку слева направо.
- При **добавлении новой ноды** панель автоматически случайно выбирает один из **доступных шаблонов** и отправляет его с изображениями на новую ноду. Пока достаточно разных шаблонов, повторы не возникают; далее распределение выравнивается по частоте использования.
- Ручное изменение шаблона сохраняется и не перезаписывается автоподбором. Временно неудавшаяся отправка повторяется. **Существующие ноды не перенастраиваются**.
- Проверка email на установке агента, включая удаление случайных посторонних символов по краям ввода.

## Установка панели с Nodes Lab v21 одной командой

В ветке `nodes-lab` установка панели теперь **автоматически включает** итоговую сборку нод. На чистом VPS, если нужна именно *основная панель*, достаточно одной команды:

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/nodes-lab/install.sh" -o /tmp/wpo-nodes-install.sh && bash /tmp/wpo-nodes-install.sh; code=$?; rm -f /tmp/wpo-nodes-install.sh; exit $code'
```

`install.sh` из `nodes-lab` клонирует **эту же ветку**, запускает оригинальную установку WPO 3.0, затем автоматически применяет конечную сборку Nodes Lab v21. Не требуется отдельно запускать патчи v1–v21. Устанавливаемая в основной панели команда **«Ноды → Добавить ноду»** всегда отдаётся через защищённый маршрут и использует итоговый `wpp-node-agent-install.sh` версии Node Agent 0.2 с правками email и публикации сайтов. Геолокация, статусы и случайный шаблон на новой ноде обеспечиваются основной панелью.

**Если чистый VPS нужен не для основной панели, а как дополнительная нода**, устанавливать на него WPO нельзя: откройте уже действующую WPO → «Ноды» → «Добавить ноду», сгенерируйте команду и запустите **только её** на дополнительном VPS.

Полная установка из ветки `nodes-lab` и этот комплексный установщик не проходили сквозной тест на реальном чистом VPS; сначала проверять на тестовом сервере.

## Применение сохранённой версии

**Только на основном VPS, где уже установлена WPO 3.0:**

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/TonyMaster14/web-panel-online/nodes-lab/wpo-nodes-lab-release-v22-install.sh" -o /tmp/wpo-nodes-release-v21.sh && bash /tmp/wpo-nodes-release-v21.sh; code=$?; rm -f /tmp/wpo-nodes-release-v21.sh; exit $code'
```

Общий установщик скачивает и проверяет *все* обновления **из закреплённого коммита**, пропускает уже обнаруженные этапы, устанавливает финальный Node Agent с исправлениями v10–v12, создаёт резервную копию и в случае ошибки восстанавливает исходные исполняемые файлы панели. Реестры пользователей и нод не стираются. На работающем экземпляре, где v21 уже установлен, повторная установка **не требуется**.

## Важно

- Сохранены **исходники и установщики в GitHub**, а не копия данных запущенного VPS. Действующие секреты, клиентские профили, DNS, ключи агента и настройки из `/var/lib/tproxy-panel` в репозиторий не загружаются.
- На данном этапе Node Agent 0.2 поддерживает HTTPS-страницу, шаблоны, регистрацию и мониторинг; **автоматическая установка VPN-транспортов и выпуск VPN-профилей на удалённой ноде ещё не реализованы**.
- Установщик рассчитан на структуру файлов WPO 3.0; новая полная инсталляция и откат на реальном VPS по этому комплексному скрипту ещё требуют отдельного тестирования. Не запускать его без необходимости на рабочем сервере.
- Ветка `main` не затронута. Все дальнейшие эксперименты проводить в `nodes-lab`.

## Исправление v22

На ширине экрана с тремя карточками статистики третья нода или установка теперь появляется в первом ряду справа от Чехии; ход установки сокращается в нижней строке с разделителем и кнопкой удаления, не выходит за границы карточки. Для уже работающей панели достаточно отдельного `wpo-nodes-lab-v22-install.sh`; весь комплекс заново ставить не нужно.
